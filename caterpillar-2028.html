03 / Technology

Autonomy is the emissions strategy nobody expected

An autonomous haul cycle holds a tighter line, brakes less and idles less than a human shift can sustain over ten hours. The fuel saved is the same fuel not burned.

Autonomous hauling

Driverless haul fleets running production sites around the clock, with the same fleet software supervising mixed autonomous and crewed machines.

Digital twins

A live model of each machine, fed by onboard telemetry, that predicts the component failure before the component fails and books the rebuild in advance.

Electrified powertrains

Battery-electric machines, charging infrastructure and the energy-management layer that decides when a site draws from the grid and when it draws from storage.

06 / Agent interface

The accessibility tree, published on purpose

For people: every browser already builds a second, simplified copy of this page for screen readers. It is called the accessibility tree. It throws away the layout and the styling and keeps only what matters for using the page: the role of each thing (is it a link, a button, a heading, a checkbox), its name (the words a screen reader would announce), and its state (is it checked, expanded, disabled, current). Normally that tree is invisible. On this page it is published, and you can read it in the console below.

For agents: the same tree is available programmatically. Call window.CAT.help() for the full surface. Nothing on this page is behind a hover menu, a carousel or a second page load, so the tree below is the whole site.

Role

What kind of control it is. link, button, checkbox, radio, heading, navigation. Taken from the element itself or its explicit ARIA role.

Name

The words that identify it, worked out the way a screen reader works it out: aria-labelledby, then aria-label, then the native label, alt text or caption, then its own text.

State

What it is doing right now. expanded, checked, disabled, current, heading level, the href a link points at.

No scripting? Still readable.

A static manifest sits in the markup as <script type="application/json" id="cat-page-manifest">. A fetch-and-parse agent gets the site index, the goals, the news and every image description without executing anything.

Stable handles

Every operable element carries data-agent-id and, where the effect is not obvious from the name, data-agent-action in plain language. Ids do not change between renders.

One page, six destinations

The 2026 site put roughly ninety links behind five hover menus. Everything here is one document and six in-page anchors, so an agent reaches any fact in a single load.
